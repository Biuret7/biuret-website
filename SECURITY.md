# Security policy

Biuret repositories are public portfolio records. They do not distribute application source code, binaries, private configuration, or sensitive implementation details.

## Reporting a security issue

Please report potential vulnerabilities privately to **adam7.workspace@gmail.com** with:

- the affected project or URL;
- a concise description and expected impact;
- safe reproduction conditions; and
- any non-sensitive supporting evidence.

Do not include passwords, private keys, personal data, destructive proof, or tests that disrupt a third-party service. Public disclosure should wait until the report has been reviewed and a reasonable remediation window has passed.

## Scope and responsible use

Network, OSINT, and security projects described here are intended for educational, research, and authorized security work only. Users are responsible for obtaining permission and following applicable law and platform policy.
