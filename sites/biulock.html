BiuLock.

A Windows password manager for encrypted credentials, payment cards, TOTP entries, file attachments, secure backups, and trusted-device exchange.

OVERVIEW

Privacy, made more deliberate.

BiuLock protects vault data and attachments with a random encryption key wrapped by the user’s password through Argon2id. Its design keeps data local, preserves legacy vaults safely, and focuses on practical recovery rather than fragile promises.

PROJECT SCOPE

Built for real-world control.

Encrypted vault

Credentials, cards, TOTP records, and file attachments are protected with a deliberate local security model.

Device Mesh

Trusted devices exchange signed pairing cards, snapshots, and secure Capsules without cloning device identity.

Recovery first

Encrypted backups validate before restoration, while expired licenses preserve read-only access for export and backup.

Focus: Delivering a polished local-first vault with secure exchange, recovery, and a refined reduced-motion-aware interface.
