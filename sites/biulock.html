CONCEPT SUMMARY

Privacy with practical control.

BiuLock explores how a personal vault can remain useful without treating security as an invisible detail. The experience prioritizes local ownership, clear state, and recovery-aware decisions.

PLANNED FEATURES

Built around everyday trust.

Organized private vault

Planned capability: Important records are kept in one focused workspace designed around privacy and clear organization.

Companion access

Planned capability: Desktop and mobile experiences are designed to work together while preserving deliberate user control.

Recovery-aware design

Planned capability: Backup and recovery flows are treated as core product experiences rather than last-minute utilities.

THE USER JOURNEY

A useful problem comes first.

Who would use it?

People who want private records organized on their own device, with a recovery process they can understand.

The problem to solve

Scattered records and unclear backups make everyday storage and recovery difficult. A useful vault must make its state and failure cases visible.

A proposed everyday flow

Add a record, organize it, create a backup and test restoration. Mobile access would follow only after the local workflow has been validated.

NEXT IMPLEMENTATION STEPS

A plan to validate, then build.

Proposed milestones, not completed deliverables.

  1. Validate the local vault workflow

    Map creation, editing, backup and recovery before implementing companion access.

  2. Prototype with established cryptography

    Define a threat model and use reviewed libraries. Existing experimental code is not evidence of secure storage.

  3. Test recovery and failure states

    Exercise wrong passwords, damaged files and interrupted writes before any release decision.

Project status: This page is a future product plan. Repository code is experimental and does not represent a released, validated, or deployment-ready application.
