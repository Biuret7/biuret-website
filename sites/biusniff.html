BiuSniff.

OVERVIEW

Seeing what moves across a network.

BiuSniff makes packet-level learning tangible in a controlled environment. It turns captured traffic into readable protocol details, raw hex views, DNS answers, TLS server-name context, and reportable capture data.

PROJECT SCOPE

Capture, inspect, understand.

Packet decoding

Live capture data is organized into readable protocol, address, port, payload, and raw-hex context.

DNS & TLS context

DNS answers and TLS Server Name Indication help make network conversations easier to interpret.

Capture reports

Selected packet data and capture metadata can be exported as a concise PDF reference.

Focus: Supporting careful network analysis learning only on systems and environments where capture is authorized.
